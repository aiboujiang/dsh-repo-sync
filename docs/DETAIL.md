# 仓库同步

把工作区里的 git 仓库定时提交并推送到远程。

## 它做什么

- 每 N 分钟（默认 15）扫描一次工作区
- 找到**已经是 git 仓库、且配了 origin** 的目录
- 有改动就 `git add -A && git commit`，然后 `git push`

## 它**不**做什么

这四条是刻意设计的，不是没做完：

| 不做 | 为什么 |
| --- | --- |
| **不自动 `git init`** | 否则工作区里任何目录都会变成仓库，包括你不想要的那些 |
| **不自动建远程仓库** | 建仓库要账号权限，这种事不该由定时任务替你做 |
| **不 force push** | 远程有你的本地没有的提交时，强制推会**永久丢掉**那些提交 |
| **不绕过 git hook** | 不加 `--no-verify`，你配的 pre-commit 检查照常生效 |

## 冲突时怎么办

如果某个仓库落后远程（别人或另一台机器推过东西），它会：

1. 照常提交本地改动（不丢你的工作）
2. **不推送**，状态标成「需 pull」
3. 在日志和面板里写明落后几个提交

处理方式：

```bash
cd <那个仓库>
git pull --rebase     # 或 git pull
```

然后再点一次「立即同步」。

## 排除别人的仓库

工作区里如果有**别的项目的 clone**（参考代码、`vendor/` 之类），
它也会被当成待同步仓库 —— 而且会推到**那个项目自己的**远程上。

所以设置里有「排除的目录名」：

```
vendor, other-clone, *-test
```

支持 `*` 通配。

## 看有哪些仓库、勾选要同步哪些

面板里列出**全部候选**仓库，每个带一个勾选框：

- 标着 **「插件」** 徽章的，是 `package.json` 里有 `dsh.bundle` / `dsh.client` 的目录
- 没标的通常是普通仓库（比如你的汇总备份库）

### 两种模式

| 「只同步勾选的」 | 行为 |
| --- | --- |
| **关**（默认） | 全部候选仓库都同步，勾选框是灰的 |
| **开** | 只有打了勾的参与同步，没勾的标「不同步」 |

⚠️ 必须先打开「只同步勾选的」，勾选框才能点 —— 这是故意的：
避免你以为勾了就等于排除了，结果没开开关、全都在同步。

### 勾选存在哪

```
~/.dsh/repo-sync/selection.json
```

里面同时记了**绝对路径**和**目录名**，所以目录挪位置或改名时，
只要还能对上一个，勾选就不会丢。

## 镜像规则（采集 → 汇总库）

有些内容是「先采集到暂存仓库、再搬进真正会推送的仓库」的两段式流程：

```
采集脚本  →  dsh-config（暂存，无 remote）
                    ↓ 镜像
              dsh-private/config（有 remote，会推送）
```

插件本身不做采集逻辑，它只负责**调用采集脚本 + 执行镜像 + 提交推送**。

「镜像规则」一行一条，格式是 `源绝对路径 => 目标绝对路径`：

```
/home/you/dsh-config => /home/you/dsh-private/config
```

用 `rsync -a --delete --exclude=.git` 执行，所以源删了文件、目标也会删。
**目标目录里别放源里没有的东西** —— 会被 `--delete` 清掉。

## 设置项

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 自动同步 | 开 | 关掉只停定时器，手动同步照常能用 |
| 间隔（分钟） | 15 | 1–1440 |
| 工作区目录 | 自动探测 | 只扫下一层带 `.git` 的目录 |
| 排除的目录名 | 空 | 逗号分隔，支持 `*` |
| 自定义提交信息 | 空 | 留空 = `chore: 自动同步 2026-01-01 12:00` |
| 启动后自动跑一次 | 关 | 开了会在 DSH 启动 10 秒后同步一次 |

## 文件在哪

```
~/.dsh/repo-sync/config.json   设置
~/.dsh/repo-sync/sync.log      同步日志
~/.dsh/repo-sync/state.json    上次运行的结果
```

## 和 shell 脚本比

这个插件就是原来那套 `systemd timer + shell 脚本` 的替代品。区别：

| | shell 脚本 | 这个插件 |
| --- | --- | --- |
| 配置 | 改脚本里的变量 | 设置页 |
| 看到状态 | 翻日志文件 | 面板直接列每个仓库 |
| 换机器 | 要重装 timer | 跟着 DSH 走 |
| 冲突处理 | 自己看 `push` 的报错 | 结构化标记 + 原因 |
